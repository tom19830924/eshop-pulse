No Xcode project or UI has been created yet. When implementation begins, keep
the Xcode project, application target, and its tests in this directory. The App
will download the normalized catalog DTO from GitHub Pages:

```text
https://tom19830924.github.io/eshop-pulse/normalized/games.json
```
